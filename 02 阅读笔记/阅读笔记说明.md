# 阅读笔记说明

02 是**来源消化层**：把一本书、一篇文章、一门课读成「我理解了什么」。它回答的是「作者说了什么、怎么论证的」，不是「我最终怎么看」。

## 写作规则

- 一篇来源一篇笔记；同一主题的多篇短文可以合并成一篇「批次笔记」，一篇一个 `##` 小节。
- 必填 `source_type`：`文章` / `书籍` / `课程` / `播客` / `视频` / `论文` / `网页`。
- 有链接就填 `source_url`；链接失效时保留文字出处，不要删掉来源。
- 引用原文要标出**哪一段**；转述要能脱离原文读懂。
- 最后写「可提炼的观点」，但**不要在这里建卡**。建卡是 03/04 的事。
- 读完把 `status` 从 `待阅读` 改为 `已沉淀`。如果结论有时效性，改为 `需复习` 并填 `evidence_as_of`。

## 不该出现在这里的

- 没有来源的原创想法（放 01 或 03）
- 已经成形的判断（放 03 或 04）
- 单纯的链接列表（那是待读清单，不是阅读笔记）

## 子目录

- `A 书籍/`
- `B 文章/`
- `C 课程/`
- `D 其他/`（播客、视频、论文、网页）

`source_type` 应与子目录对应；审计 B11 会提醒不一致的情况。
