# 模板库

7 个核心模板。用 Obsidian 的 **Templates** 核心插件插入，或用 `tools/kb_new.py` 在终端创建。

## 模板清单

| 模板 | 用于 | 初始 type | 初始 status |
|---|---|---|---|
| [[_模板_临时想法]] | 一句话捕获、当天日记 | `inbox` | `待整理` |
| [[_模板_阅读笔记]] | 书 / 文章 / 课程 / 其他来源的消化 | `reading` | `待阅读` |
| [[_模板_主题笔记]] | 一个主题下的「我的判断」 | `topic` | `待提炼` |
| [[_模板_常青卡]] | 原子概念 / 原则 / 模型 / 方法 / 判断 / 金句 | `evergreen` | `草稿` |
| [[_模板_项目主页]] | 有交付物的项目 | `project` | `待启动` |
| [[_模板_复盘]] | 项目或事件的复盘 | `review` | `草稿` |
| [[_模板_每周回顾]] | 每周 30 分钟收口 | `review` | `草稿` |

## 关键设计：模板是「实例种子」

模板里的 `type` 与 `status` 是**新建笔记应该长的样子**，不是模板自己的状态：

- 用阅读笔记模板新建 → 得到 `type: reading` / `status: 待阅读`
- 用常青卡模板新建 → 得到 `type: evergreen` / `status: 草稿`
- 用项目主页模板新建 → 得到 `type: project` / `status: 待启动`

很多模板库会在这里写 `status: active`，结果每篇新建笔记一开始就处于非法状态，必须手动改。本库不这样做。

模板目录 `07 资料库/D 模板/` 被审计脚本整体跳过，因此 `{{date}}` 之类的占位符不会报错。

## 占位符

| 占位符 | 替换为 |
|---|---|
| `{{title}}` | 文件名（不含 `.md`） |
| `{{date}}` | 当天日期 `YYYY-MM-DD` |
| `{{date:格式}}` | 自定义日期，支持 `YYYY` / `MM` / `DD` / `HH` / `mm` / `ss` |
| `{{time}}` | 当前时间 `HH:mm` |

以上占位符由 Obsidian Templates 与 `kb_new.py` 共同支持；`kb_new.py` 还替换 `{{year}}`、`{{area}}`、`{{source_type}}`、`{{form}}`。`area`、`source_type`、`form` 在模板里给了默认值，按需修改；`kb_new.py` 会用 `--area` / `--source-type` / `--form` 自动覆盖。

## 改模板的规则

1. 只改这个目录里的模板。
2. 改完跑 `python3 tools/kb_audit.py`，确认模板目录仍被跳过、示例库没有新问题。
3. 如果改了 `type` / `status` 的初始值，同步更新本页表格与 `tools/kb_config.json`。
