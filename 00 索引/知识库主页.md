# 知识库主页

这是每天打开库时先看的一页。上面的四个查询块是**工作台**，不是装饰：它们为空时，说明上游没有输入，而不是维护已经完成。

## 今天先做一件事

按 `Cmd/Ctrl + P` 打开命令面板，运行 **Daily notes: Open today's daily note**。光标会落在 `01 收件箱/A 临时想法/` 的当天笔记里，写一句话就算完成捕获。

想用模板新建其他笔记，见 [[模板库]]；想在终端里建，运行 `python3 tools/kb_new.py --help`。

## 收件箱

还没判断归属的捕获都在这里。每周至少清一次。

```query
path:"01 收件箱" -file:"收件箱说明"
```

> 这里长期为空，先问自己：这周有没有任何新想法、摘录或待读？如果没有，问题在输入，不在整理。

## 消化队列

等待从素材变成判断的笔记。

```query
([status:待阅读] OR [status:待提炼]) -path:"99 归档" -path:"07 资料库" -path:"01 收件箱"
```

## 进行中的项目

项目状态只看真实动作，不看文档里写了什么。

```query
path:"05 项目" file:项目主页 [status:进行中]
```

## 需复习

结论依赖时效证据、需要复核的笔记。复核后要么补新证据，要么降级，**不要只改状态**。

```query
[status:需复习] -path:"99 归档"
```
